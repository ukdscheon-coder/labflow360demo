2. Applicable official sources

Selecting a country filters official source links; it does not import verified full legal requirements.

3. Register verified requirements

Enter a requirement from the official source, including its precise clause and effective date. A reviewer must verify it before it can be treated as approved.

4. Upload QM / SOP / supporting documents

Text extraction supports TXT, JSON, and text-based PDF/DOCX when browser libraries load. Scanned images need OCR and are not supported. Files stay in this browser; do not upload confidential patient or staff data.

5. Matching candidates & improvement workflow

The matching engine uses text similarity only. A match is a review candidate, not proof of compliance. Missing evidence does not prove non-compliance.

6. Backup / restore

Browser-local only. Export contains document text. Import resets reviews to unverified.
