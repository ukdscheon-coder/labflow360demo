# Regulatory changelog — LabFlow 360

Every change to a regulation, standard, guideline, law, notice or requirement used by this app is recorded here.
Owner rule (DS, 05/11/2026):

1. Strengthen only what is missing or weak in the current version. Never change the app's basic structure or existing rules.
2. Before changing regulatory content, find the latest version on the website of the **public body that issued it** (not a third-party summary).
3. Apply the change only when the official text matches the content being applied **and** its issue or effective date is newer than the version in the app. Otherwise leave the app unchanged and note what differs.
4. Add an entry below for every applied change. A change without an entry, or without an official source, is incomplete and must not be merged.

Dates are DD/MM/YYYY. Newest entry first.

## Entry format

| Field | Content |
|---|---|
| Applied | date the change went into the app |
| Item | regulation / standard / clause / data record changed |
| Previous | version, number and issue or effective date in the app before the change |
| New | version, number and issue or effective date applied |
| Issuing body | e.g. MFDS, FDA, MHRA, EU Commission, ISO, UKAS |
| Official source | URL on the issuing body's site, retrieval date, file hash if stored |
| What changed | short description of the difference |
| Verification | how the official text was matched (quote, article number, hash) and who checked it |
| Files | files changed in this repository |
